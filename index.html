Designed around gestures

Interaction, reimagined.

Four simple gestures form the core of the touchless viewing experience.

⌕

Pinch to zoom

Bring thumb and index finger together to control image zoom.

✣

Gesture to pan

Use the index-finger gesture to navigate around the image.

↻

Open-palm rotation

Rotate the displayed image with an open-palm gesture.

Ⅱ

Pause interaction

Use a closed fist to pause gesture-based controls.

Project overview

Made to explore.

This project explores hands-free human-computer interaction for medical image viewing. The desktop application uses a webcam to detect gestures and interact with a selected image.

Run locally

Try the project.

Clone the repository, install the dependencies in requirements.txt, then launch the Python desktop interface.
