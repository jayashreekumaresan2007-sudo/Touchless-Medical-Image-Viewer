Gesture-driven interaction

Control the image.
Not the mouse.

Four gesture controls form the core of this hands-free viewing prototype.

⌕

Pinch to zoom

Use thumb and index-finger movement to control image zoom.

✣

Gesture-based pan

Navigate the image using the index-finger gesture.

↻

Open-palm rotation

Rotate the image using an open-palm gesture.

Ⅱ

Pause interaction

Use a closed fist to pause gesture-based controls.

The engineering

Built with computer vision.

A Python desktop prototype combining hand tracking, image processing and a graphical interface.

PythonOpenCV MediaPipeNumPy CustomTkinterPillow

The concept

Designed for hands-free exploration.

This project explores human-computer interaction through webcam-based hand gesture recognition, with a focus on touchless image navigation.
