Gesture-driven interaction

Control the image.
Not the mouse.

Use your webcam to experiment with hands-free image navigation.

🤏

Pinch to zoom

Bring your thumb and index finger together and move them apart to adjust zoom.

☝

Gesture-based pan

Point with your index finger to move around the image.

✋

Open-palm rotation

Show an open palm and move your hand horizontally to rotate the image.

✊

Pause interaction

Make a fist to pause gesture-based controls.

The engineering

Built with computer vision.

The original desktop application uses Python and MediaPipe. This live web demo uses browser-compatible JavaScript hand tracking.

Python desktop app OpenCV MediaPipe JavaScript web demo HTML & CSS Canvas API

The concept

Designed for hands-free exploration.

This project explores human-computer interaction through webcam-based hand gesture recognition and touchless image navigation.
